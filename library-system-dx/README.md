# Library System DX

Java 17製の、全画面・キーボード操作の図書館管理CLIアプリです。Lanternaを使ってターミナルに画面を描画します。最初の起動では操作例として本8冊、利用者4名、貸出2件、予約1件を作成します。以後の変更は `data/library.properties` に自動保存されます。

## 起動

Windowsではターミナルをこのディレクトリで開き、`run.cmd` を実行してください。付属の `runtime` がある場合はそれを使います。Unix系ではJava 17以上を用意して `./run.sh` を実行します。画面は78列×24行以上を推奨します。

全画面操作に対応していない端末では、自動で行入力モードに切り替わります。明示的に使う場合は `java -jar target/library-system-dx-1.0.0.jar --plain` とします。行入力モードは番号付きメニューで画面を切り替え、`next` と `prev` で一覧のページを移動できます。`search` で絞り込み、`clear` で解除、`help` でコマンド一覧を表示します。色表示を止めたい場合は環境変数 `NO_COLOR` を設定してください。

ソースからビルドする場合は、Java 17以上とMavenを用意し、このディレクトリで `mvn package` を実行します。完成した実行ファイルは `target/library-system-dx-1.0.0.jar` です。`java -jar target/library-system-dx-1.0.0.jar` でも起動できます。Mavenは初回ビルド時にLanternaなどの依存ファイルをダウンロードします。

## 主な機能

| 画面 | できること |
| --- | --- |
| 概要 | 蔵書・貸出・延滞の件数、要対応の貸出を確認 |
| 本 | 登録、編集、一覧、検索、詳細表示、保管 |
| 利用者 | 登録、編集、一覧、検索、詳細表示、無効化 |
| 貸出 | 貸出、返却、期限延長、履歴の閲覧 |
| 予約 | 貸出中の本を予約、待ち順の確認、予約取消 |
| 分析 | 稼働率、累計貸出、分類別冊数を表示 |
| 履歴 | 最近250件の操作記録を表示 |

貸出は1冊につき同時に1件です。利用者ごとの上限は初期値3冊、貸出期間は初期値14日で、`S` キーから変更できます。予約がある本は待ち順の先頭の利用者を優先します。期限延長は2回までで、延滞中または予約待ちがある場合はできません。本や利用者は削除せず、貸出履歴を残したまま保管・無効化します。

## 操作

| キー | 動作 |
| --- | --- |
| `←` `→` / `1`〜`8` | 画面切替 / 画面へ直接移動 |
| `↑` `↓` / `PgUp` `PgDn` | 一覧の選択・移動 |
| `Enter` | 詳細表示 |
| `/` | 一覧の絞り込み検索 |
| `N` | 本・利用者・予約の登録、貸出登録 |
| `E` | 本・利用者の編集、貸出期限の延長 |
| `D` | 本の保管、利用者の無効化、予約取消 |
| `L` / `R` | 貸出 / 返却 |
| `S` | 貸出設定 |
| `Esc` | 検索解除、概要画面へ戻る |
| `?` / `Q` | ヘルプ / 終了 |

フォームでは `Tab` や `↑` `↓` で欄を移動します。最後の欄で `Enter`、またはどの欄でも `F2` で保存します。`Esc` で取り消します。

## 構成

- `App` — 全画面表示とキーボード入力
- `PlainCli` — 行入力モードの画面とコマンド
- `LibraryService` — 登録・貸出・予約などの業務ルール
- `LibraryState` — 本・利用者・貸出・予約・履歴のデータ
- `LibraryStore` — 保存と読み込み

保存ファイルは一時ファイルへ書いてから置き換えます。初回のデータをやり直したい場合は、アプリを終了してから `data/library.properties` を別名で保管し、再起動してください。
