# 図書館管理システム Java 基礎演習

## 目的

標準ライブラリを中心に、図書館の本と利用者を管理するコンソールアプリを作成する。
演習は上から順番に進める。最初はメモリ上のデータだけで動かし、最後に外部ファイルへ保存する。

## 開発ルール

- Java 17 で作成する。
- Maven プロジェクトの `src/main/java` にプログラムを書く。
- テストは `src/test/java` に書く。
- パッケージ名は `com.example.library` 以下にする。
- まずは標準入力・標準出力を使う。GUIやデータベースは使用しない。
- 1つのメソッドに処理を詰め込みすぎず、役割ごとにクラス・メソッドを分ける。

## 最終仕様

図書館員が、次の操作を行えるシステムを作る。

1. 本を登録する
2. 本の一覧を表示する
3. タイトルまたは著者名で本を検索する
4. 利用者を登録する
5. 本を貸し出す
6. 本を返却する
7. 貸出中の本を表示する
8. データをファイルに保存する
9. 保存したデータを起動時に読み込む

本には「ID、タイトル、著者名、貸出状態」を持たせる。
利用者には「ID、氏名、貸出中の本のID一覧」を持たせる。

---

## 第1問：コンソールにメニューを表示する

`App.java` を実行したとき、次のメニューを表示する。

```text
==== 図書館管理システム ====
1. 本の一覧を表示
2. 本を検索
3. 本を登録
4. 利用者を登録
5. 本を貸し出す
6. 本を返却する
0. 終了
番号を入力してください:
```

番号を受け取り、`0` が入力されるまでメニューを繰り返す。
まだ未実装の番号は「この機能は未実装です」と表示する。

### 学習項目

- `Scanner`
- `while`、`switch`
- 標準入力と標準出力

## 第2問：本を表すクラスを作る

`Book` クラスを作成し、次のフィールドを持たせる。

- `int id`
- `String title`
- `String author`
- `boolean borrowed`

コンストラクタ、ゲッター、貸出状態を変更するメソッド、内容を表示するための `toString()` を実装する。

表示例：

```text
ID: 1 / タイトル: Java入門 / 著者: 山田太郎 / 状態: 貸出可能
```

## 第3問：本を配列またはリストで管理する

最初から登録されている本を3冊用意し、一覧表示機能を実装する。
まず配列で実装してもよいが、登録件数を増やしやすくするため、次の段階で `ArrayList<Book>` に変更する。

### 条件

- 本が0冊の場合は「登録されている本はありません」と表示する。
- 一覧にはID、タイトル、著者、貸出状態を表示する。

### 学習項目

- 配列
- `ArrayList`
- 拡張 `for` 文
- オブジェクトの集合

## 第4問：本を登録する

タイトルと著者名を入力して、本を登録する。
IDは重複しないように自動採番する。

### 条件

- タイトルが空文字なら登録しない。
- 著者名が空文字なら登録しない。
- 登録成功時に発行したIDを表示する。

## 第5問：本を検索する

入力されたキーワードを含む本を検索する。
タイトルまたは著者名にキーワードが含まれていれば表示する。

### 条件

- 大文字・小文字を区別するかどうかを自分で決め、仕様書に記録する。
- 該当する本がなければ、そのことを表示する。
- 検索処理を専用メソッドに分ける。

## 第6問：利用者クラスを作る

`Member` クラスを作成し、次の情報を持たせる。

- `int id`
- `String name`
- 貸出中の本のID一覧

貸出上限は1人3冊とする。
利用者の登録、利用者一覧の表示、IDによる検索を実装する。

## 第7問：貸し出し処理を実装する

利用者IDと本IDを入力し、本を貸し出す。

### 貸し出しできない条件

- 指定した利用者が存在しない。
- 指定した本が存在しない。
- 本がすでに貸出中である。
- 利用者が3冊借りている。

条件に該当する場合は、原因を分かりやすく表示する。
貸し出しに成功した場合は、本を貸出中にし、利用者の貸出本一覧に本のIDを追加する。

## 第8問：返却処理を実装する

利用者IDと本IDを入力し、本を返却する。

### 条件

- 指定した利用者が存在しない。
- 指定した本が存在しない。
- 本が貸出中ではない。
- その利用者が借りていない本を返却しようとしている。

返却に成功した場合は、本を貸出可能にし、利用者の貸出本一覧から本のIDを削除する。

## 第9問：クラスを分割する

処理が増えてきたら、次のクラスに分割する。

```text
App              メニュー表示と入力受付
LibraryService   本・利用者の登録、検索、貸出、返却
Book             本のデータと状態
Member           利用者のデータと貸出本
```

`App` が本の内部フィールドを直接変更しないようにする。
貸出や返却のルールは `LibraryService` に集める。

## 第10問：例外と入力エラーに対応する

数字を入力すべき場所に文字が入力されても、プログラムが終了しないようにする。

### 対応する入力エラー

- メニューにない番号
- 数字以外のID
- 存在しないID
- 空のタイトルや氏名
- 負の数

エラーメッセージを表示した後、メニューに戻る。
必要に応じて `try-catch` を使用する。

## 第11問：ユニットテストを書く

`src/test/java` にテストを追加する。

最低限、次のテストを作成する。

- 本を登録できる
- 空のタイトルを登録できない
- 存在する本を検索できる
- 貸出可能な本を貸し出せる
- 貸出中の本を二重に貸し出せない
- 貸出上限を超えて借りられない
- 貸出した本を返却できる
- 借りていない本を返却できない

テストは次のコマンドで実行する。

```text
mvn test
```

## 第12問：外部ファイルに保存する

プログラム終了時に、本と利用者のデータをファイルへ保存する。
起動時にはファイルを読み込み、前回の状態を復元する。

保存先の例：

```text
data/books.csv
data/members.csv
```

### 条件

- `Files`、`Path`、`BufferedReader`、`BufferedWriter` などを使用する。
- ファイルが存在しない初回起動では、空のデータから開始する。
- 読み込みに失敗した場合は、原因を表示して安全に終了する。
- データにカンマや改行が含まれる場合の扱いを仕様書に記録する。

## 第13問：仕上げ

次の内容を追加して完成度を上げる。

- 貸出日時と返却期限
- 返却期限を過ぎた本の表示
- 本の削除・編集
- 利用者名の検索
- 操作履歴のログ出力
- README.md への実行方法の記載
- `docs` へのクラス構成図・操作仕様書の追加

## 完成条件

- `mvn test` が成功する。
- `mvn package` が成功する。
- 起動、登録、検索、貸出、返却、終了、再起動後の読み込みができる。
- 不正な入力をしても異常終了しない。
- 本番コードとテストコードが適切なディレクトリに分かれている。
- 主要なクラスとメソッドに、役割が分かる名前が付いている。
